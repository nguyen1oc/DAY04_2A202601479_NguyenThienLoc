# Calculator Tool

This tool evaluates simple mathematical arithmetic expressions safely.

## When to use
Use this tool when the user asks for basic arithmetic calculations (e.g. addition, subtraction, multiplication, division, percentage calculations, e.g., "25000 * 1.1").

## When NOT to use
Do NOT use this tool for advanced mathematics, algebra, calculus, integration, solving equations, or programming tasks. These remain out of scope.
